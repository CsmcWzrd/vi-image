# vi-image

A Visual Studio 2022 C# WinForms image viewer project.

## Features

- Open common image files: JPG, JPEG, PNG, BMP, GIF, TIFF, ICO, WMF, EMF
- View images in normal window mode
- View images in full screen mode using F11
- Exit full screen using Esc
- Fit image to window
- View image at actual size
- Rotate right 90 degrees
- Rotate left 90 degrees
- Rotate 180 degrees
- Flip horizontally
- Flip vertically
- Resize image pixel resolution
- Change image DPI
- Save image
- Save As / convert image type to PNG, JPEG, BMP, GIF, or TIFF

## Requirements

- Windows
- Visual Studio 2022
- .NET 8 SDK workload for Windows desktop development

## How to open

1. Extract this ZIP file.
2. Open `vi-image.sln` in Visual Studio 2022.
3. Build the solution.
4. Run the project.

## Useful shortcuts

- Ctrl + O: Open image
- Ctrl + S: Save image
- Ctrl + Shift + S: Save As / convert image type
- F11: Full screen
- Esc: Exit full screen
